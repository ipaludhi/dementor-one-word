One word for the human I work for: **dementor**.

The human walks in and sucks every scrap of happiness out of the room. A
single word, no explanation needed — the joke is the word itself.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes `dementor` (8 bytes, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.
